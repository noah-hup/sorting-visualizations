Sortier- & Suchalgorithmen

Interaktive Animationen zum Einbetten (z. B. in Notion via Embed-Block).

Binary Search

Schrittweise Suche in einem sortierten Array.

Selection Sort

Array in sortierten und unsortierten Bereich aufteilen.

Bubble Sort

Größte Elemente wandern durch Tauschen nach rechts.

Rank Sort

Rang durch Zählen kleinerer Elemente bestimmen.

Index Sort

Array bleibt unverändert, ein Index-Array wird sortiert.

Radix Sort

Ziffer für Ziffer per Counting Sort einsortieren.

Insertion Sort

Werte nacheinander in den sortierten Bereich einfügen.

Merge Sort

Aufteilen bis n=1, dann sortiert zusammenfügen.

Quick Sort

Pivot wählen, in kleiner/größer aufteilen, rekursiv wiederholen.
